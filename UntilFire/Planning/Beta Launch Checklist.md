# Beta Launch Checklist

UntilFire’s next launch path is friends-and-family beta first, then soft public launch on Reddit/X, then Product Hunt only after the beta gate is met.

## Current beta audience

Family and friends only.

Do not optimize for random public users yet. Use beta to learn what users want and where the product should go next.

## Beta goal

Learn:

1. Is this what users want?
2. What should John build next?
3. What causes dropoff?

## Readiness gate before wider launch

Minimum gate from the roadmap:

- [ ] 50 real visitors.
- [ ] 20 completed freedom-date results.
- [ ] 5 feedback replies.
- [ ] Zero critical flow issues.

Stronger gate:

- [ ] 100 visitors.
- [ ] 50 completed results.
- [ ] 10 people willing to support/comment for a public launch.
- [ ] Zero critical flow issues.

## Must be true before inviting family/friends

- [ ] Homepage CTA starts the calculator clearly.
- [ ] No-login calculator can be completed on mobile.
- [ ] Result shows freedom date and at least one monthly move.
- [ ] User is not asked to log in before seeing value.
- [ ] User is not asked to pay during the first experience.
- [ ] Feedback is hidden unless the user opens it.
- [ ] No star ratings are shown.
- [ ] Feedback prompt appears only after the result, if at all.
- [ ] Any visible feedback entry says “Help us improve this for you.”
- [ ] No bank/Plaid prompt is central to the beta path.
- [ ] Copy avoids making the user feel judged, hopeless, or pressured.

## Dropoff signals to watch

- Users do not click the first CTA.
- Users start but do not finish the calculator.
- Users stop at financial input steps.
- Users reach the result but do not understand it.
- Users feel the result is too scary or hopeless.
- Users do not know what to do next.
- Feedback, login, paywall, or bank prompts cause hesitation.
- Mobile layout hides the main action or makes the page feel busy.

## Beta feedback collection

Feedback should answer:

- Was this useful?
- What did you want to do next?
- What felt confusing or missing?
- What would make this worth coming back to?

Do not use star ratings during early beta.
