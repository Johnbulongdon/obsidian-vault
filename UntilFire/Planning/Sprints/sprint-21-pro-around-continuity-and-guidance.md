# Sprint 21 — Pro Around Continuity and Guidance

**Status:** 🔲 Planned  
**Module:** Monetisation → Guidance-Led Pro Packaging  
**Phase mapping:** Phase 6 — Repackage Pro around continuity and guidance  
**Goal:** Align monetization with the new promise.

## Problem

If paid value is framed as generic dashboard access, feature quantity, or friction before the aha moment, it conflicts with UntilFire’s positioning. Pro should feel like help, continuity, and smarter guidance — not like a trap.

## User story

As a user who has already received real value, I want the paid upgrade to feel like deeper support for my path — so paying feels like getting help, not unlocking a wall.

## Done when

- [ ] Paid framing moves away from:
  - generic dashboard access
  - “more features” language
  - paywalling the first aha moment
- [ ] Paid framing moves toward:
  - monthly guidance
  - better continuity
  - smarter next moves
  - ongoing progress support
- [ ] Free still provides a real first value moment before any paid ask.
- [ ] Pro clearly deepens the path rather than replacing the free product’s core usefulness.
- [ ] Upgrade language feels supportive, calm, and aligned with the product promise.

## Acceptance criteria

- Free gives real first value.
- Paid deepens the path.
- Pro feels like help, not a trap.
- Upgrade surfaces do not pressure users before the result and first useful next move.
- Monetisation language matches the broader financial-freedom positioning.

## Out of scope

- Aggressive paywall experiments before the guidance loop is strong
- Monetisation-first redesigns that weaken the first-value path
- Pricing complexity for its own sake
- Expanding paid value claims beyond what the product can actually deliver
