# Repo and Vault Boundary

## Decision

Use Obsidian as the UntilFire information layer and keep the GitHub repository focused on code.

## What belongs in Obsidian

- Product strategy and positioning
- Roadmaps and sprint plans
- Personas and user journey notes
- Market research and launch/content calendars
- Decision logs and audit notes
- Agent context that is not required for code execution

## What belongs in the repo

- Source code
- Tests
- Package/config files
- Minimal setup instructions needed to run the app
- Minimal agent rules required for safe code changes
